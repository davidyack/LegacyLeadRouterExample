# Terminology

The governed vocabulary for this product. Each entry records what the word means and, where one exists, the authority that governs it.

## Named Account Lead Assignment — as used in davidyack/LegacyLeadRouterExample

A lead-assignment rule for accounts that have been explicitly named or designated.

- **Applies to**: both
- **Status**: provisional

## Source-Specific Lead Routing — as used in davidyack/LegacyLeadRouterExample

A routing policy that assigns leads according to the source from which they originated.

- **Applies to**: both
- **Status**: provisional
